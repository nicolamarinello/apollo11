# Project instructions

- Historical Apollo 11 only: P63 → P64 → crew-assisted P66 → touchdown. No alternative autonomous landing.
- Verified simulation playback is the intended milestone. Until a validated capture exists, label the current archival callout playback candidly. Never fabricate telemetry, a trajectory, fuel curves or execution highlights.
- Preserve the dark navy technical-illustration style, small stylized lander, restrained gold, minimal UI and thin red phase timeline. Open into the experience; no marketing page.
- Keep evidence data, playback, rendering and educational annotations separate. Preserve source attribution, pinned revisions, hashes, original units and missing values.
- Before committing changes, run the relevant playback tests, source-integrity check and production build. For evidence changes, run the reference audit and review provenance.
- Project repository: `git@github.com:nicolamarinello/apollo11.git`. Use the system SSH agent/keychain and existing macOS keychain credential helper. Never extract credentials or save tokens in project files. Git author is Nicola Marinello with the repository-local GitHub no-reply email.
- See `docs/PLAN.md`, `docs/PROVENANCE.md` and `docs/TRACE_CONTRACT.md` before claiming a verified playback milestone.
